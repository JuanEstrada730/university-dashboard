# University Student Data Dashboard

Interactive dashboard developed with Streamlit to analyze admission, retention, and student satisfaction data from a university between 2015 and 2024.

## Description

The goal is to interactively visualize key indicators from the `university_student_data.csv` dataset using dynamic charts and filters.

## Repository contents

- `Data Visualization` — main Streamlit dashboard application
- `university_student_data.csv` — dataset used for the analysis
- `requirements.txt` — libraries needed to run the application
- `README.md` — project description

## Included visualizations

- KPI cards with average retention, satisfaction, and enrolled students
- Line chart: retention trend by year
- Bar chart: student satisfaction by year
- Bar chart: comparison between Spring and Fall terms
- Pie chart: distribution of enrolled students by department
- Filtered data table

## Available filters

- Year (2015 - 2024)
- Term (Spring, Fall, or All)
- Department (Engineering, Business, Arts, Science)

## How to run locally

1. Clone the repository
```
git clone https://github.com/your-username/your-repository.git
```

2. Install the dependencies
```
pip install -r requirements.txt
```

3. Run the application
```
streamlit run app.py
```
